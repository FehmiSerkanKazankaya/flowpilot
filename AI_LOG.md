# AI Kullanım Kaydı

Bu projede yapay zeka araçlarını geliştirme sürecinde yardımcı araç olarak kullandım.

## ChatGPT

Kullanım alanları:

- Projenin temel mimarisini planlama
- Next.js proje yapısını oluşturma konusunda yönlendirme
- Form doğrulama senaryolarını belirleme
- API route yapısını oluşturma
- Supabase entegrasyonu sırasında hata durumlarını değerlendirme
- README ve proje dokümantasyonunu düzenleme

AI tarafından önerilen kodları doğrudan kabul etmek yerine projede çalıştırarak ve çıktıları kontrol ederek kullandım.

Özellikle form gönderim sürecinde başarı mesajının yalnızca veritabanı kaydı gerçekten başarılı olduğunda gösterildiğini test ettim.
